# 新版前端（Vue）部署说明

> 适用：把 `前端/` 这套 Vue + Element Plus 界面换到线上服务器。
> 后端仍是原来的 Python 服务，**不用改数据库、不用装 Java、不用装 Nginx**。

---

## 1. 原理

Python 服务启动时检查 `前端/dist/index.html` 是否存在：

- **存在** → 用新前端当主界面，`/`、`/entry`、`/ledger`… 都返回新前端
- **不存在** → 自动退回旧版 `网页/`，不会白屏

所以部署是「加一个目录」，回滚是「删一个目录」。

---

## 2. 本地打包（Windows）

```bat
cd /d "D:\2026\04-信宇科技\02-人数发票登记系统\前端"
npm install
npm run build
```

产物在 `前端\dist\`，一共十几个文件：

```
dist\
├── index.html
└── assets\        index-xxxx.js / index-xxxx.css / 各页面分包
```

> 打包报 `Access is denied`（杀毒软件锁临时目录）时：
> ```bat
> set TMP=%CD%\.tmpbuild
> set TEMP=%CD%\.tmpbuild
> npm run build
> ```

---

## 3. 上传到服务器

用 XFTP / WinSCP 上传这两个东西：

| 本地 | 服务器 |
|---|---|
| `前端\dist\` 整个目录 | `/opt/02-fapiaodengji/前端/dist/` |
| `程序\server.py` | `/opt/02-fapiaodengji/程序/server.py` |

`node_modules` **不要传**（几十兆，服务器用不上）。

---

## 4. 服务器上生效

```bash
cd /opt/02-fapiaodengji

# 1) 权限（用 root 传的文件服务用户读不了，必做）
sudo chown -R invoice:invoice 前端 程序

# 2) 重启（HAS_SPA 是启动时判断的，传完必须重启）
sudo systemctl restart invoice-ledger

# 3) 确认认得新版
curl -s http://127.0.0.1:8765/ | head -c 200
#   看到 <script type="module" crossorigin src="/assets/index-xxxx.js">
#   就是新版；看到 <link rel="stylesheet" href="/static/style.css"> 是旧版

# 4) 健康检查
curl -s http://127.0.0.1:8765/_health
#   ok fd=xxx/65536
```

浏览器 **Ctrl + F5** 强制刷新。

## 6. 回滚（30 秒）

**方式一：切旧版界面，不重启**

浏览器直接访问：

```
http://124.220.163.141:8765/old
```

`/old` 就是原来的界面，功能一模一样。

**方式二：彻底回到旧版**

```bash
sudo mv /opt/02-fapiaodengji/前端/dist /opt/02-fapiaodengji/前端/dist.off
sudo systemctl restart invoice-ledger
```

删掉（或改名）`dist` 后，服务自动用回 `网页/`。

## 7. 以后每次改前端

```bash
# 本地
cd 前端 && npm run build

# 上传 dist 覆盖
# 重启
sudo systemctl restart invoice-ledger
```

只改前端、不改 `程序/` 的话，其实**不用重启**也能生效——
但 `dist` 目录是启动时判断存在的，第一次部署必须重启一次。

---

## 8. 常见问题

**Q：首页 500 / 报「读不到网页文件」**
`dist` 是 root 上传的，`invoice` 用户读不了。执行第 4 步的 `chown`。

**Q：刷新 `/ledger` 出现 404**
`程序/server.py` 还是旧版（没有 SPA 兜底路由），传新版 server.py 后重启。

**Q：改了前端没变化**
`index.html` 是 `no-store`，正常不会缓存；多半是没重新打包或没覆盖 `dist`。
`assets/` 下的文件名带 hash，不会读到旧的。

**Q：想同时保留两套给人选**
新版在 `/`，旧版在 `/old`，两边共用同一个数据库和接口，随时可切。
