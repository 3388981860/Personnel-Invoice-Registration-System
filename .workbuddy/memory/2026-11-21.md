# 2026-11-21 工作日志

## 人数发票登记系统 · 角色互动登录页

### 背景
用户上传一张Q版鲨鱼兽娘女仆角色图（藏青+天蓝+白配色），要求基于此图设计可操作的角色互动登录页，并导出完整演示GIF。需遵循详细提示词：14秒时间轴、10个分幕、绝对时间渲染、真实输入+自动演示接管、分幕点播、减少动态效果、GIF导出。

### 设计决策
- **配色**：沿用版本B政务深蓝调性（#1B4F8C + 金色 #C8A45C），与角色蓝发配色契合
- **角色呈现**：白色拱形角色台从卡片顶部探出，角色图居中其内。去掉 mix-blend-mode:multiply（会干扰叠加层渲染），改用白色角色台天然融合JPG白底
- **叠加层**：CSS真实子元素（`<b>`标签）+ Unicode字符（★❤zZ✦✿）绘制表情（闭眼弧线/倒八字眉毛/笑嘴/难过嘴/星星眼/爱心眼/Z字/汗滴/加载圈/撒花），头部transform实现摇头/点头/转头/回避/偷瞄/弹跳/下沉
- **时间轴**：10个分幕（待机0-1.9s→输入邮箱1.9-4.3s→出错4.3-5.3s→改对5.3-6.7s→回避密码6.7-7.8s→偷瞄7.8-9.0s→准备提交9.0-10.1s→检查中10.1-11.1s→成功11.1-12.5s→困倦12.5-14.0s），window.__render(t)绝对时间渲染，?rec定帧模式

### 技术难点与解决
- **headless Chrome截图限制**：innerHTML创建的SVG、CSS伪元素background、mix-blend-mode在puppeteer截图/element.screenshot中均不渲染。最终叠加层全部改用CSS真实子元素+Unicode字符
- **GIF导出**：node-canvas编译失败（Windows缺构建工具），html2canvas遇tainted canvas，gif.js worker跨域限制。最终方案：启动本地HTTP服务器 + page.evaluate内用canvas API手动绘制每帧 + fetch下载gif.worker.js创建Blob URL inline worker + gif.js合成GIF
- **GIF用canvas API完全重绘**：不依赖DOM截图，每帧用ctx.drawImage画角色图+ctx.arc/lineTo/fillText画叠加层+表单+光标+成功覆盖
