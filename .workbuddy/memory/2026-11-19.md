## 人数发票登记系统 · 界面设计三版交付

### 背景
用户要求基于现有发票系统代码，设计系统所有界面，出三版供对比，设计图放在 `D:\2026\08-系统设计图\01-人数发票登记系统` 下。加载了「企业级 UI 页面设计优化」skill。

### 系统功能梳理（基于代码 + 操作说明 + 升级方案）
- **核心模块**：登录/注册、新建报销单（拖拽上传 PDF/OFD + OCR + 单头表单 + 本单发票表）、登记台账（筛选+表格+分页+批量操作）、发票详情抽屉、报销单详情抽屉（审核端）、数据总览（8 KPI + 3 图表 + 2 排行榜）、用户管理 + 操作日志、消息通知面板、查验进度浮层、审核退回弹窗
- **状态体系**：报销状态（未/已/部分报销）、审核状态（待审/退回/通过）、查验状态（通过/不通过/未查/无需查）
- **角色**：管理员（全权限）/ 普通用户（仅自己的单据）
- 技术栈：Python 标准库 + SQLite + 原生 JS + ECharts，单页应用 hash 路由

### 三版设计方向
1. **版本A · 经典企业蓝**（Ant Design 风格）：主色 #1677FF，顶栏导航，8px 圆角，对标阿里/华为云

3. **版本C · 极简浅灰**（现代台账风格）：主色 #111114 墨黑，大留白，10px 圆角，对标 Notion/Linear
