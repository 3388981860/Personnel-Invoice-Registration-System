  人数发票登记台账  操作说明
════════════════════════════════════════════════════════════

一、怎么打开
────────────────────────────────────────────
双击本文件夹里的「启动.bat」。

会弹出一个黑色窗口，然后浏览器自动打开台账界面。
不用的时候：直接关掉黑色窗口就行（浏览器关掉不影响，数据已经存好了）。

下次再用，还是双击「启动.bat」。
如果系统已经在运行，再双击一次不会开出第二个，只会把浏览器重新叫起来。


二、登记一单报销（一张单里可以有很多张发票）
────────────────────────────────────────────
一次报销往往有好几张发票，系统是按「报销单」来管的：
一张报销单下面挂 N 张发票，报销人、收款人、报销日期只填一次。

第 1 步   把这一单的发票【一次全部拖进】左上角的虚线框。
          （也可以点它选文件；支持 PDF / OFD）

第 2 步   发票会自动识别，列成「本单发票」表。
          每行的 发票号码 / 开票日期 / 金额 / 销售方 都能直接改。

第 3 步   填【报销人】【收款人】【报销日期】，备注选填。
          这几个是给整单填的，填一次就行。

第 4 步   看一下「本单发票」右边「提示」列：
              ✓ 正常      —— 没问题
              黄底提醒    —— 号码不是 20 位 / 没读出金额 / 取自二维码，可以看一眼
              红底       —— 这张之前登记过，不能提交，请点「移除」去掉

第 5 步   点「提交报销单」。

系统自动生成一个单号（如 BX20261021-001），
本单所有发票一起登记，发票原件一起存进「发票存档」。

● 单号可以自己填（比如按公司现有单据号），留空就自动生成。
● 只有一张发票也要报销？一样的流程，拖一张、提交，就是一张单。
● 手边没有电子发票只想登记号码：点「＋ 手工加一行」，手打号码即可。


三、查重怎么体现（重点）
────────────────────────────────────────────
登记时会自动查两遍：

    第 1 遍（拖进来的时候）：
        某张发票之前登记过 —— 那一行整行变红，
        「提示」列写明「⛔ 这张之前登记过了」。

    第 2 遍（点提交的时候）：
        只要本单里有任何一张重复，整单都提交不了，
        上面会弹出红条告诉你具体是哪一张。

另外，同一张单里如果出现两次相同号码，也会标红提醒。

系统只按【发票号码】判重，金额或日期一样不算重复。


四、报销完了，把开关打开（整单一起）
────────────────────────────────────────────
点台账里的【报销单号】，右侧滑出「报销单详情」：

    ● 上面是单头：单号、报销人、收款人、报销日期、状态、合计、张数
    ● 中间是明细表：本单每一张发票的号码/日期/金额/状态
    ● 底下有个大按钮：整单标记已报销

    新登记的单默认是「未报销」（红底白字）。
    钱付出去了，点一下「整单标记已报销」，
    单里每一张发票一起变成「已报销」（绿底白字），并记下确认时间。

点错了不要紧，再点「整单改回未报销」就切回去了。

台账每一行也有一个独立的小开关，可以单独改某一张票的状态。
整单状态会显示成：整单已报销 / 未报销 / 部分已报销（2/3）。

界面上方一直显示一行醒目的：
      【待报销 X 单 / Y 张　合计 ¥ZZZ】
这就是你现在还欠着、还没报销的钱，一眼就知道。


五、想查以前的记录
────────────────────────────────────────────
界面下半部分就是台账，列了：

    ☑ / 报销单号 / 发票号码 / 开票日期 / 金额(含税) / 报销人 /
    收款人 / 报销状态 / 备注 / 操作

● 搜索框：输号码、单号、公司名、报销人、收款人、备注，都能搜。
● 四个下拉：按报销人筛、按月份筛、按报销状态筛、按报销单筛
  （选「未归单」可以只看还没归到任何报销单的发票）。
● 点表头（报销单号 / 发票号码 / 开票日期 / 金额 / 报销人 /
  报销状态）可以排序。

【看某张发票的全部信息】
    点表格里的任意一行（或最右边的「详情」按钮），右侧滑出详情面板：
        发票号码、开票日期
        金额（含税）、不含税金额、税额
        销售方、购买方、项目
        报销单号、报销人、收款人、报销日期
        报销状态、报销确认时间
        备注、登记时间、原件文件名和存放位置
    面板底部按钮：查看原件 / 修改 / 打开报销单 / 删除
    按 Esc 或点面板外面关掉。

【收款人这一列怎么看】
    ● 收款人和报销人不一样时，会显示成橙色带 ⚠ 的标记，
      付款前一眼就能注意到，不会付错人。
    ● 显示「待填」= 这条还没填收款人（还没报销的记录），
      点开详情补上就行。
    ● 显示「—」= 升级前的老记录没填收款人，已经报销完了就不用管。


六、把已经登记过的发票归到同一张单（补挂）
────────────────────────────────────────────
有时候发票是零散登记的，后来才知道它们属于同一单。
不用重新录，勾一下就行：

    第 1 步   在台账最左边勾选要归到一起的那几张发票
    第 2 步   下面会浮出一条操作栏，选：
              「新建报销单」           —— 给这几张建一张新单（可以起单号）
              「加入已有报销单…」      —— 选一张已有的单放进去
              「从单里拆出」           —— 反悔了，把它们拿出来变回「未归单」

归到已有单里的发票，会跟随那张单的报销人 / 收款人 / 报销日期。


七、导出 Excel
────────────────────────────────────────────
点右上角「⬇ 导出 Excel」，会下载一份完整的台账表格。

表格列：报销单号 / 发票号码 / 开票日期 / 金额(价税合计) / 不含税金额 /
        税额 / 销售方 / 购买方 / 项目 / 报销人 / 收款人 / 报销日期 /
        报销状态 / 报销确认时间 / 备注 / 登记时间

另外，系统每次保存都会自动同步一份最新的表格在：
    数据\发票台账.xlsx
随时可以直接用 Excel 打开看，不用打开系统。

  但目标电脑要装 Python 3.10 以上版本。
★ 备份只要拷「数据」和「发票存档」两个文件夹就够。


九、常见问题
────────────────────────────────────────────
问：双击启动.bat 闪一下就没了？
答：说明那台电脑没装 Python。到 python.org 下载安装，安装时务必勾选
    "Add python.exe to path"，然后重新双击。

问：提交报销单时提示某张发票重复？
答：那张发票之前登记过，不能重复报销。在「本单发票」里点「移除」去掉它，
    再提交；如果确认是两张不同的票，请核对发票原件。

问：提交时提示「有发票号码是空的」？
答：有一行只拖了文件但没读出号码。手工把那 20 位号码填进去，或移除那一行。

问：发票号码不是 20 位提示了，能提交吗？
答：会再问你一次，确认后可以提交。

问：金额读出来好像不对？
答：金额取的是票面【价税合计】（含税总额）。系统还会用大写金额反向核对，
    对不上会黄字提醒。确认不对，直接在「本单发票」里改那一行的金额即可。

问：会不会把发票原件弄丢？
答：不会。系统只往「发票存档」复制一份，你原来的文件原地不动。
    删除记录时原件也只是挪进「数据\已删除」，不会真正删除。

问：升级前登记的老记录怎么办？
答：老记录会自动显示成「未归单」，状态、金额、原件一切照旧，一条不丢。
    想整理就按第六节的办法，勾几行归到一张单里。


十、打包发给同事 / 搬到别的电脑
────────────────────────────────────────────
一定要【整个文件夹一起压缩】，不能只发「启动.bat」这一个文件。
压缩时请在上一级目录（比如 D:\2026\04-信宇\）右键整个文件夹压缩，
不要进到文件夹里全选文件再压缩，那样会少一层。

同事拿到压缩包后，正确的三步：

    1. 先把压缩包【完整解压】成一个文件夹
       （右键压缩包 →「全部解压到当前文件夹」）

    2. 进入解压出来的那个文件夹

    3. 双击里面的 启动.bat

★ 千万不要在压缩包里直接双击 启动.bat ！
  Windows 允许你在压缩包里浏览、并直接双击里面的文件，
  但那样只会把这一个 bat 临时解出来，旁边的「程序」「网页」
  「运行库」三个文件夹都不在，程序一秒就退出，窗口里显示：

        [启动失败] 找不到程序文件 server.py
        ...
        系统已退出，数据已实时保存。

  —— 只要看到「系统已退出，数据已实时保存」，几乎都是这个原因，
     跟浏览器被拦截、防火墙都没有关系。

同事电脑上需要装的东西：只有 Python 3.10 以上版本
（官网 python.org 下载，安装时务必勾选 "Add python.exe to PATH"）。


十一、已经用起来了，怎么升级（千万别整个覆盖）
────────────────────────────────────────────
对方已经登记了数据，就【不能】把整个文件夹发过去覆盖，
那样会把「数据」和「发票存档」一起盖掉。正确做法：

    1. 先关掉那边的黑色窗口（文件被占用会替换不成功）

    2. 只把升级包里的「程序」「网页」两个文件夹，以及 启动.bat、
       操作说明.txt，拖过去覆盖

    3. 重新双击 启动.bat

    第一次启动会自动升级数据库结构（加报销单表和新栏位），几秒钟就好。

★ 升级时「数据」和「发票存档」两个文件夹绝对不要动，
  原来的记录、报销状态、发票原件全部都在，一条都不会少。
★ 如果浏览器打开还是老样子，按一下 Ctrl + F5 强制刷新。
