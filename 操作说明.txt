  人数发票登记台账  操作说明
════════════════════════════════════════════════════════════

一、怎么打开
────────────────────────────────────────────
双击本文件夹里的「启动.bat」。

会弹出一个黑色窗口，然后浏览器自动打开台账界面。
不用的时候：直接关掉黑色窗口就行（浏览器关掉不影响，数据已经存好了）。

下次再用，还是双击「启动.bat」。
如果系统已经在运行，再双击一次不会开出第二个，只会把浏览器重新叫起来。


二、登记一单报销（一张单里可以有很多张发票）
────────────────────────────────────────────
一次报销往往有好几张发票，系统是按「报销单」来管的：
一张报销单下面挂 N 张发票，报销人、收款人、报销日期只填一次。

第 1 步   把这一单的发票【一次全部拖进】左上角的虚线框。
          （也可以点它选文件；支持 PDF / OFD）

第 2 步   发票会自动识别，列成「本单发票」表。
          每行的 发票号码 / 开票日期 / 金额 / 销售方 都能直接改。

第 3 步   填【报销人】【收款人】【报销日期】，备注选填。
          这几个是给整单填的，填一次就行。

第 4 步   看一下「本单发票」右边「提示」列：
              ✓ 正常      —— 没问题
              黄底提醒    —— 号码不是 20 位 / 没读出金额 / 取自二维码，可以看一眼
              红底       —— 这张之前登记过，不能提交，请点「移除」去掉

第 5 步   点「提交报销单」。

系统自动生成一个单号（如 BX20261021-001），
本单所有发票一起登记，发票原件一起存进「发票存档」。

● 单号可以自己填（比如按公司现有单据号），留空就自动生成。
● 只有一张发票也要报销？一样的流程，拖一张、提交，就是一张单。
● 手边没有电子发票只想登记号码：点「＋ 手工加一行」，手打号码即可。


三、查重怎么体现（重点）
────────────────────────────────────────────
登记时会自动查两遍：

    第 1 遍（拖进来的时候）：
        某张发票之前登记过 —— 那一行整行变红，
        「提示」列写明「⛔ 这张之前登记过了」。

    第 2 遍（点提交的时候）：
        只要本单里有任何一张重复，整单都提交不了，
        上面会弹出红条告诉你具体是哪一张。

另外，同一张单里如果出现两次相同号码，也会标红提醒。

系统只按【发票号码】判重，金额或日期一样不算重复。


四、报销完了，把开关打开（整单一起）
────────────────────────────────────────────
点台账里的【报销单号】，右侧滑出「报销单详情」：

    ● 上面是单头：单号、报销人、收款人、报销日期、状态、合计、张数
    ● 中间是明细表：本单每一张发票的号码/日期/金额/状态
    ● 底下有个大按钮：整单标记已报销

    新登记的单默认是「未报销」（红底白字）。
    钱付出去了，点一下「整单标记已报销」，
    单里每一张发票一起变成「已报销」（绿底白字），并记下确认时间。

点错了不要紧，再点「整单改回未报销」就切回去了。

台账每一行也有一个独立的小开关，可以单独改某一张票的状态。
整单状态会显示成：整单已报销 / 未报销 / 部分已报销（2/3）。

界面上方一直显示一行醒目的：
      【待报销 X 单 / Y 张　合计 ¥ZZZ】
这就是你现在还欠着、还没报销的钱，一眼就知道。


五、想查以前的记录
────────────────────────────────────────────
界面下半部分就是台账，列了：

    ☑ / 报销单号 / 发票号码 / 开票日期 / 金额(含税) / 报销人 /
    收款人 / 报销状态 / 备注 / 操作

● 搜索框：输号码、单号、公司名、报销人、收款人、备注，都能搜。
● 四个下拉：按报销人筛、按月份筛、按报销状态筛、按报销单筛
  （选「未归单」可以只看还没归到任何报销单的发票）。
● 点表头（报销单号 / 发票号码 / 开票日期 / 金额 / 报销人 /
  报销状态）可以排序。

【看某张发票的全部信息】
    点表格里的任意一行（或最右边的「详情」按钮），右侧滑出详情面板：
        发票号码、开票日期
        金额（含税）、不含税金额、税额
        销售方、购买方、项目
        报销单号、报销人、收款人、报销日期
        报销状态、报销确认时间
        备注、登记时间、原件文件名和存放位置
    面板底部按钮：查看原件 / 修改 / 打开报销单 / 删除
    按 Esc 或点面板外面关掉。

【收款人这一列怎么看】
    ● 收款人和报销人不一样时，会显示成橙色带 ⚠ 的标记，
      付款前一眼就能注意到，不会付错人。
    ● 显示「待填」= 这条还没填收款人（还没报销的记录），
      点开详情补上就行。
    ● 显示「—」= 升级前的老记录没填收款人，已经报销完了就不用管。


六、把已经登记过的发票归到同一张单（补挂）
────────────────────────────────────────────
有时候发票是零散登记的，后来才知道它们属于同一单。
不用重新录，勾一下就行：

    第 1 步   在台账最左边勾选要归到一起的那几张发票
    第 2 步   下面会浮出一条操作栏，选：
              「新建报销单」           —— 给这几张建一张新单（可以起单号）
              「加入已有报销单…」      —— 选一张已有的单放进去
              「从单里拆出」           —— 反悔了，把它们拿出来变回「未归单」

归到已有单里的发票，会跟随那张单的报销人 / 收款人 / 报销日期。


七、导出 Excel
────────────────────────────────────────────
点右上角「⬇ 导出 Excel」，会下载一份完整的台账表格。

表格列：报销单号 / 发票号码 / 开票日期 / 金额(价税合计) / 不含税金额 /
        税额 / 销售方 / 购买方 / 项目 / 报销人 / 收款人 / 报销日期 /
        报销状态 / 报销确认时间 / 备注 / 登记时间

另外，系统每次保存都会自动同步一份最新的表格在：
    数据\发票台账.xlsx
随时可以直接用 Excel 打开看，不用打开系统。


八、东西都存在哪
────────────────────────────────────────────
发票存档\2026\09\26327000001715695220.pdf   ← 发票原件，按年月分好
数据\发票台账.db                            ← 主数据库（系统的命根子）
数据\发票台账.xlsx                          ← 自动同步的 Excel 台账
数据\备份\                                  ← 每天第一次打开时自动备份一份
数据\已删除\                                ← 删除的记录，原件挪到这里，不真删

★ 想整个搬到别的电脑：把「02-人数发票登记系统」整个文件夹拷过去即可，
  但目标电脑要装 Python 3.10 以上版本。
★ 备份只要拷「数据」和「发票存档」两个文件夹就够。


九、常见问题
────────────────────────────────────────────
问：双击启动.bat 闪一下就没了？
答：说明那台电脑没装 Python。到 python.org 下载安装，安装时务必勾选
    "Add python.exe to path"，然后重新双击。

问：提交报销单时提示某张发票重复？
答：那张发票之前登记过，不能重复报销。在「本单发票」里点「移除」去掉它，
    再提交；如果确认是两张不同的票，请核对发票原件。

问：提交时提示「有发票号码是空的」？
答：有一行只拖了文件但没读出号码。手工把那 20 位号码填进去，或移除那一行。

问：发票号码不是 20 位提示了，能提交吗？
答：会再问你一次，确认后可以提交。

问：金额读出来好像不对？
答：金额取的是票面【价税合计】（含税总额）。系统还会用大写金额反向核对，
    对不上会黄字提醒。确认不对，直接在「本单发票」里改那一行的金额即可。

问：会不会把发票原件弄丢？
答：不会。系统只往「发票存档」复制一份，你原来的文件原地不动。
    删除记录时原件也只是挪进「数据\已删除」，不会真正删除。

问：升级前登记的老记录怎么办？
答：老记录会自动显示成「未归单」，状态、金额、原件一切照旧，一条不丢。
    想整理就按第六节的办法，勾几行归到一张单里。


十、打包发给同事 / 搬到别的电脑
────────────────────────────────────────────
一定要【整个文件夹一起压缩】，不能只发「启动.bat」这一个文件。
压缩时请在上一级目录（比如 D:\2026\04-信宇\）右键整个文件夹压缩，
不要进到文件夹里全选文件再压缩，那样会少一层。

同事拿到压缩包后，正确的三步：

    1. 先把压缩包【完整解压】成一个文件夹
       （右键压缩包 →「全部解压到当前文件夹」）

    2. 进入解压出来的那个文件夹

    3. 双击里面的 启动.bat

★ 千万不要在压缩包里直接双击 启动.bat ！
  Windows 允许你在压缩包里浏览、并直接双击里面的文件，
  但那样只会把这一个 bat 临时解出来，旁边的「程序」「网页」
  「运行库」三个文件夹都不在，程序一秒就退出，窗口里显示：

        [启动失败] 找不到程序文件 server.py
        ...
        系统已退出，数据已实时保存。

  —— 只要看到「系统已退出，数据已实时保存」，几乎都是这个原因，
     跟浏览器被拦截、防火墙都没有关系。

同事电脑上需要装的东西：只有 Python 3.10 以上版本
（官网 python.org 下载，安装时务必勾选 "Add python.exe to PATH"）。


十一、已经用起来了，怎么升级（千万别整个覆盖）
────────────────────────────────────────────
对方已经登记了数据，就【不能】把整个文件夹发过去覆盖，
那样会把「数据」和「发票存档」一起盖掉。正确做法：

    1. 先关掉那边的黑色窗口（文件被占用会替换不成功）

    2. 只把升级包里的「程序」「网页」两个文件夹，以及 启动.bat、
       操作说明.txt，拖过去覆盖

    3. 重新双击 启动.bat

    第一次启动会自动升级数据库结构（加报销单表和新栏位），几秒钟就好。

★ 升级时「数据」和「发票存档」两个文件夹绝对不要动，
  原来的记录、报销状态、发票原件全部都在，一条都不会少。
★ 如果浏览器打开还是老样子，按一下 Ctrl + F5 强制刷新。


十二、发票查验（辨真伪）
────────────────────────────────────────────
系统可以把发票送到「国家税务总局全国增值税发票查验平台」核验真伪，
查验结果和结果截图都会存进台账，以后随时能查、能当凭证。

【怎么查】
    方式一（批量）：在台账里勾选要查的发票 → 点「查验选中」
    方式二（单张）：点开某张发票的详情 → 点底部的「查验这张」
    一张也没勾就点「查验选中」的话，系统会问你要不要查
    全部「未查验 / 上次没通过」的发票。

    查验时浏览器是在后台跑的，屏幕上不会弹任何窗口，
    你只会看到右下角那个进度小窗——这就是"无感"的效果。
    （万一想看它到底在干什么：把「数据\查验配置.json」里 headless 改成 false，
      重启后就会弹出浏览器窗口，调试完记得改回 true。）
    右下角有个进度小窗，能看到正在查哪一张、已经成功几张。
    想中途停：点进度窗里的「停止查验」，当前这张查完就停。

【结果怎么看】
    台账新增了一列「查验」：
        查验通过（浅绿）—— 平台确认发票信息一致
        查验不通过（浅红）—— 平台说信息不一致 / 查无此票，点开看说明
        未查验（灰）    —— 还没查，或者上次验证码没识别出来
        无需查验（灰）  —— 开票超过 5 年，平台本来就不给查

    点开某张发票的详情，往下能看到「查验结果」：
        查验状态、查验时间、查验说明（平台原话）
        结果截图（点一下看大图）—— 这就是这张票已经查验过的凭证

    台账上面的「全部查验」下拉，可以只看未查验的、或只看没通过的。

【要知道的几件事】
    ● 平台的规矩：同一张发票每天最多查 5 次，所以别反复点。
      已经查通过的，30 天内不会再重复查（省次数）。
    ● 每查一张大约 3～7 秒，后台一个个串行处理，别同时开两个查验任务。
    ● 验证码是程序自动识别的，偶尔会识别错，程序会自己重试；
      重试几次还不行，那张会显示「未查验」，过一会儿再点一次就行。
    ● 第一次用之前，如果提示"浏览器没装好"，请让管理员在命令行执行一次：
          python -m playwright install chromium
      双击「自检.bat」也能看到查验组件齐不齐。
    ● 查验只证明"平台上有这张票、信息一致"，不代替业务审核；
      真要报销前，抬头、金额、报销人这些还是自己看一眼。

【查验通过了，但后面有个橙色感叹号？】
    那不是查验失败，是系统发现的、需要你留意的问题：
        ⚠ 购买方不是本公司 —— 抬头开错了，这种票一般不能报销
        ⚠ 金额较大 —— 超过设定的金额线，建议二次确认
    点开详情，「需要留意」那一栏会把每一条写清楚。
    这些提示不影响"查验通过"的结论，也不拦着你提交，只是让人多看一眼。
    （抬头白名单、大额线可以在「数据\查验配置.json」里改，改完重启生效。）

    以下两条默认不点感叹号，只在详情里用灰字轻轻提一句：
        · 收款人和报销人不是同一人 —— 详情里写「一点提示」，付款前确认一下。
          这条太常见（代报、家人代收），做成感叹号会让人麻木；
          改对了人，提示会立刻消失，不用重新查验。
        · 跨月报销 —— 公司习惯次月报，默认关掉。
          想重新打开：把「数据\查验配置.json」里的 warn_cross_month 改成 true，重启即可。

【为什么有的票显示"信息不一致"】
    系统会把台账里登记的号码、开票日期、价税合计，和平台返回的逐项比对。
    只要有一样对不上，就标成「查验不通过」并写明差在哪，
    比如：价税合计不一致（台账 16.52 / 平台 16.00）。
    这种情况通常是在台账里改过金额或日期，建议核对后改回来再查一次。

【整单一起查】
    点台账里的报销单号，右侧会滑出「报销单详情」：
        ● 「查验情况」一行汇总本单：通过 2 / 未查 1 …
        ● 下面的明细表多了一列「查验」，每张票什么状态一眼看到
        ● 底部有「查验本单」按钮 —— 只查还没通过的那几张，
          已经通过的不会再浪费次数

【台账标题上的查验概况】
    「登记台账」标题右边会写：查验 通过 7 / 未查 1 …
    后面还有一句「本月 X 张：通过 Y」，方便按月看这个月查了多少。

【登记时就自动判断"这票不用查"】
    开票日期超过 5 年的、发票号码位数不对的（不是 20 位也不是 8 位），
    登记完系统会直接标成「无需查验」并写明原因，
    这样以后点「查验选中」时，它不会被反复拿去平台白跑一趟。
